Über diese App

Dieses Museum Quiz ist eine Progressive Web App – sie kann direkt auf dem Homescreen installiert werden und funktioniert auch offline.

Laden Sie Ihre eigene sammlung.json hoch, um die Objekte Ihrer Sammlung zu durchsuchen und daraus automatisch ein Quiz zu generieren.

Die JSON-Datei sollte Objekte mit den Feldern titel, künstler und jahr enthalten.

Beispiel JSON-Format

[
  {
    "titel": "Die Sternennacht",
    "künstler": "Vincent van Gogh",
    "jahr": "1889",
    "bild_url": "https://..."
  }
]
